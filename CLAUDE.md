# office

## gstack

- Use the `/browse` skill from gstack for all web browsing. Never use `mcp__claude-in-chrome__*` tools.
- gstack skills (`/office-hours`, `/spec`, `/autoplan`, `/review`, `/qa`, `/ship`, ...) are installed globally in `~/.claude/skills/gstack`.

## pstack

- pstack is installed as the Claude Code plugin `pstack@cursor-plugins`. Its commands are prefixed, e.g. `/pstack:poteto-mode`.
- Run `/pstack:setup-pstack` once to choose models before using `/pstack:poteto-mode`.
